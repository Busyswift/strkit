# Security policy

strkit has no network access, no file I/O and no runtime dependencies, so its
attack surface is small. If you find a security problem anyway (for example,
catastrophic regex backtracking on crafted input), report it privately through a
[GitHub security advisory](https://github.com/sheepdogs/strkit/security/advisories/new)
rather than a public issue. You'll get a response within a week.
